# Домен: Музичний стрімінговий сервіс (на прикладі Spotify)

## Опис домену

Цей проект моделює базову структуру даних для платформи музичного стрімінгу, яка є спрощеним аналогом Spotify. Основна бізнес-мета системи — забезпечити взаємодію між авторами музики (виконавцями) та слухачами (користувачами).

Користувачі можуть знаходити музику, організовувати її у власні плейлисти та взаємодіяти з контентом. Виконавці випускають альбоми, які складаються з окремих треків. Система також підтримує колаборації (коли у треку є кілька виконавців) та збереження улюблених треків користувачами.

## Ключові процеси

Каталогізація музики: Збереження інформації про виконавців, їхні альбоми та треки.

Організація контенту користувачем: Створення плейлистів та додавання до них треків.

Взаємодія з контентом: Можливість користувача вподобати (зберегти) певний трек.
