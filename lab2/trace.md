# Матриця трасування

Обраний прецедент — **UC-02 «Організувати особистий плейлист»**. Позначка
`X` означає, що вимога перевіряється відповідним сценарієм. Матриця має
зв'язки багато-до-багатьох: одна вимога може покривати кілька сценаріїв, а
один сценарій — кілька вимог.

| Вимога-ID | Короткий зміст вимоги | S1 | S2 | S3 | S4 | S5 | UC |
|---|---|---:|---:|---:|---:|---:|---|
| FR-01 | Створити плейлист для автентифікованого користувача | X |  |  |  |  | UC-02 |
| FR-02 | Додати наявний трек до порожнього плейлиста на позицію 1 | X |  |  |  |  | UC-02 |
| FR-03 | Додати наявний трек до власного плейлиста на наступну позицію |  | X |  |  |  | UC-02 |
| FR-04 | Відхилити повторне додавання треку без зміни плейлиста |  |  | X |  |  | UC-02 |
| FR-05 | Заборонити зміну чужого плейлиста без створення запису |  |  |  | X |  | UC-02 |
| FR-06 | Перевірити автентифікацію, власність, наявність і відсутність дубліката перед додаванням | X | X | X | X | X | UC-02 |
| FR-07 | Відхилити відсутній у каталозі трек без зміни плейлиста |  |  |  |  | X | UC-02 |

## Перевірка покриття

- Усі функціональні вимоги `FR-01–FR-07` мають щонайменше один сценарій.
- Усі сценарії `S1–S5` мають щонайменше одну вимогу.
- `UC-02` покритий усіма сценаріями та вимогами.
- Непокритих функціональних вимог у межах обраного UC немає.
- NFR із [nfr.md](nfr.md) навмисно не внесені до матриці: за умовою вони
  не трасуються.
- Інші потреби домену — пошук і слухання музики, публікація релізів,
  уподобані треки та спільне редагування — не трасуються, бо вони винесені за
  межі UC-02 і для них немає сценаріїв у [sc.md](sc.md).
